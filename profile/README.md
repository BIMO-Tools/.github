## What we build

| | |
| --- | --- |
| **BIMO Add-in for Revit** | A unified workspace for running BIM automation tools inside Autodesk Revit. |
| **BIMO Library** | Reusable commands for everyday modeling, selection, documentation, and analysis workflows. |
| **Custom commands** | Extend BIMO with C# commands and Python scripts tailored to your workflows. |
| **AI Agent Access** | Connect AI agents to supported Revit operations through the BIMO MCP integration, using the same command runtime. |

Explore the products at **[bimo.tools](https://bimo.tools)**.

## Open-source projects

| Repository | Description |
| --- | --- |
| [**Bimo.Tools**](https://github.com/BIMO-Tools/Bimo.Tools) | Public .NET SDK contracts for writing custom BIMO commands. Available on [NuGet](https://www.nuget.org/packages/Bimo.Tools). |
| [**Revit-Python-Scripts**](https://github.com/BIMO-Tools/Revit-Python-Scripts) | Documented Python scripts for Revit automation, with a machine-readable catalog for discovery. |
| [**RegEx**](https://github.com/BIMO-Tools/RegEx) | Regular-expression tools for Dynamo and Revit. |

These repositories contain selected open-source tools and interfaces, **not the complete source code of the BIMO Add-in**.
